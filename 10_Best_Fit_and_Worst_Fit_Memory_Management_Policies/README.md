# Best Fit and Worst Fit Memory Management

## Aim
To implement and study Best Fit and Worst Fit memory management policies using C.

## Part A: Best Fit
Best Fit allocates each process to the smallest available memory block that is large enough to accommodate it. The remaining block size is updated after allocation.

## Part B: Worst Fit
Worst Fit allocates each process to the largest available memory block that can accommodate it. The remaining block size is reduced after allocation.

## Part C: Comparison
The program compares both methods using the same memory blocks and processes. It displays the block allocated to each process, with -1 indicating unsuccessful allocation.

## Domain and Use Case
Cloud platform virtual machine memory management.

## Result
Successfully implemented and studied Best Fit and Worst Fit memory management policies using C.
