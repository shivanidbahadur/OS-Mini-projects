# Sequential and Indexed File Allocation

## Aim
To implement and study Sequential and Indexed File Allocation methods using C.

## Part A: Sequential File Allocation
Sequential allocation stores a file in consecutive disk blocks. The program searches for a suitable sequence of free blocks and allocates them to the file.

## Part B: Indexed File Allocation
Indexed allocation uses an index block to store the addresses of a file's data blocks. This allows the file's data blocks to be accessed through the index block.

## Domain and Use Case
File storage and management systems.
