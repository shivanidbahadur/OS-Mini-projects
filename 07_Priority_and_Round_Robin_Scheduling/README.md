# Priority, Round Robin and Best/Worst Fit

This experiment demonstrates CPU scheduling and memory allocation techniques used by operating systems.

## Algorithms Implemented

1. Priority Scheduling
2. Round Robin Scheduling
3. Best Fit and Worst Fit Memory Allocation

## Programs

### Priority Scheduling

Processes are scheduled based on their priority. The process with the higher priority is selected for execution.

**File:** `Priority_scheduling/priority_scheduling.c`

### Round Robin Scheduling

Each process is given a fixed time quantum in a cyclic order. If a process is not completed within its time quantum, it waits for its next turn.

**File:** `Round_Robin_Scheduling/round_robin.c`


## Concepts Covered

- Priority Scheduling
- Round Robin Scheduling
- Time Quantum
