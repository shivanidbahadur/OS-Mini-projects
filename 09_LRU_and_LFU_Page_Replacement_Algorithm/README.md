# Experiment : LRU and LFU Page Replacement Algorithms

## Aim
To implement LRU and LFU page replacement algorithms using C.

## Part A: LRU Page Replacement
LRU (Least Recently Used) replaces the page that has not been used for the longest time. It keeps track of the last usage of each page to decide which page to replace.

## Part B: LFU Page Replacement
LFU (Least Frequently Used) replaces the page with the lowest usage frequency. It maintains a frequency count for each item and replaces the item with the lowest count when required.

## Domain and Use Case
**Supermarket Billing System:** The LFU algorithm is used to manage a cache of product IDs while processing product prices and calculating the total bill.

## Result
Successfully implemented LRU and LFU page replacement algorithms using C.
