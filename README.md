# Operating Systems Mini Projects

A collection of mini-projects developed as part of my
Operating Systems coursework. The repository covers
processes, threads, synchronization, deadlocks, and
CPU scheduling.

## Projects

1. Multithreading and Multiprocessing
   - SPMT
   - MPMT

2. Mutual Exclusion, Semaphore and Monitor
   - Mutex
   - Mutex + Semaphore
   - Mutex + Semaphore + Monitor

3. Reader-Writer Problem

4. Dining Philosophers Problem

5. Deadlocks
   - Deadlock
   - Deadlock Handling
   - Banker's Algorithm

6. CPU Scheduling
   - FCFS
   - SJF
