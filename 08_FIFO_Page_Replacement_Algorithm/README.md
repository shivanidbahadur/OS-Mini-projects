# FIFO Page Replacement Algorithm

This experiment demonstrates the FIFO page replacement technique used by an operating system to manage pages in memory.

## Algorithm Implemented

**FIFO (First In First Out)**

FIFO replaces the page that has been in memory for the longest time when a new page needs to be loaded and all frames are occupied.

## Program

The program demonstrates page or request handling using the FIFO approach.

**File:** `FIFO_Page_Replacement/fifo.c`

- Page Replacement
- FIFO
- Memory Frames
- Page Fault
- Page Replacement Order
